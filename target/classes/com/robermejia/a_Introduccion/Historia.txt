================================================== Historia de Java ====================================================
=== Orígenes y desarrollo temprano (década de 1990) ====================================================================
Java se originó en el proyecto Oak de Sun Microsystems a principios de la década de 1990. El objetivo inicial era crear
un lenguaje para programar dispositivos electrónicos integrados. James Gosling lideró el equipo de desarrollo.

El lenguaje se diseñó con la filosofía de "escribir una vez, ejecutar en cualquier lugar" (WORA), gracias a la máquina
virtual Java (JVM). Esto significaba que el código Java compilado podía ejecutarse en cualquier plataforma que tuviera
una JVM implementada.

Inicialmente, Java no tuvo mucho éxito en su objetivo original, pero con el auge de Internet, se adaptó rápidamente para
 el desarrollo de aplicaciones web, convirtiéndose en una tecnología clave para la web dinámica. Los applets de Java
 fueron populares en su tiempo.

==== El ascenso de Java (finales de la década de 1990 y principios de la década de 2000) ===============================
Java se convirtió en uno de los lenguajes de programación más populares del mundo, utilizado en una amplia gama de
aplicaciones, desde aplicaciones empresariales hasta juegos y aplicaciones móviles. J2EE (Java 2 Platform, Enterprise
Edition) surgió como una plataforma para aplicaciones empresariales a gran escala.

La aparición de frameworks como Spring simplificó el desarrollo de aplicaciones Java, aumentando su adopción. Las
colecciones de Java fueron mejoradas y se introdujeron nuevas funcionalidades al lenguaje.

==== Java en la era moderna (década de 2010 hasta la actualidad) =======================================================
Oracle adquirió Sun Microsystems en 2010, convirtiéndose en el propietario de Java. La evolución de Java continuó con
nuevas versiones (Java SE 7, 8, 11, 17, etc.), introduciendo características como las expresiones lambda, las mejoras en
 la concurrencia, y el soporte para las nuevas tecnologías.

Java continúa siendo un lenguaje dominante en el desarrollo de aplicaciones empresariales, Android (con Kotlin ganando
terreno), y en el desarrollo de aplicaciones de gran escala. La comunidad Java sigue siendo grande y activa, con una
gran cantidad de bibliotecas y frameworks disponibles.

==== Consideraciones adicionales =======================================================================================
La JVM ha sido fundamental para el éxito de Java, permitiendo su portabilidad a diferentes plataformas. La orientación a
 objetos es una característica principal de Java. La gestión de memoria automática (recolector de basura) simplifica el
 desarrollo y reduce errores.
